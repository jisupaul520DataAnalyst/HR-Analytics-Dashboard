# HR Analytics Dashboard - Power BI
## Project Overview
This project is an interactive HR Analytics Dashboard built using Power BI.
The dashboard helps analyze:
- Employee Attrition
- Department-wise Attrition
- Job Satisfaction
- Employee Demographics
- Salary Insights
- Education Field Analysis
---
## Tools Used
- Power BI
- Power Query
- DAX
- Excel
---
## Key KPIs
- Total Employees
- Total Attrition
- Attrition Ratio
- Active Employees
- Average Age
- Average Monthly Pay
---
## Dashboard Features
### 1. Employee Analysis
- Gender distribution
- Age group analysis
- Marital status insights

### 2. Attrition Analysis
- Department-wise attrition
- Job role attrition ratio
- Attrition by education field

### 3. Job Satisfaction
- Satisfaction rating by role
- Employee engagement insights
---
## Business Insights
- Highest attrition found in R&D department
- Sales Representatives have the highest attrition ratio
- Majority employees belong to Life Sciences background
- Employees aged 25-34 form the largest workforce segment
